# متطلبات تشغيل مكتبة القدس

يعمل الفهرس المحلي على Android ابتداءً من API 24. لا يحتاج التشغيل المحلي إلى خادم أو حساب أو قاعدة بيانات خارجية. يخزن التطبيق الفهرس والمفضلة في SQLite على الجهاز. فتح المراجع الخارجية يتطلب اتصالًا ويستهلك من البيانات بحسب الموقع المفتوح.

## بناء نسخة الاختبار

استخدم JDK 17 وGradle 8.9 وAndroid SDK 35. لتجهيز بيئة تطوير مع محاكي واحد، خصص مبدئيًا 4 أنوية و16 غيغابايت RAM و25 غيغابايت فارغة. هذه تقديرات تجهيز وليست قياسات. يعتمد استهلاك التنزيل الأول على SDK وصورة المحاكي وذاكرة Gradle المؤقتة.

```sh
python3 -m unittest discover -s tests -v
gradle --no-daemon testDebugUnitTest lintDebug assembleDebug
# بعد تشغيل محاكي Android 15 المخصص للاختبار
gradle --no-daemon connectedDebugAndroidTest
cd app/build/outputs/apk/debug
sha256sum *.apk > SHA256SUMS
```

## الحفظ والتوزيع

احتفظ بمصدر الفهرس المرخص ونسخ البناء وبصماتها. اختبر ترحيل قاعدة البيانات قبل توزيع أي تحديث. النسخ الاحتياطي التلقائي للتطبيق معطل، وحذف التطبيق قد يحذف المفضلة المحلية. لا يوجد تصدير مفضلة في هذا الإصدار.

يكفي GitHub Actions على مشغلات قياسية للبناء واختبارات المحاكي بعد اعتماد النشر العام، مع الاحتفاظ بحزم CI سبعة أيام. يمكن استخدام GitHub Releases للتوزيع بعد اعتماد المحتوى. لا حاجة إلى أرصدة سحابية لتشغيل الفهرس. إذا أضيفت خدمة خلفية مستقبلًا، يمكن تقييم أرصدة برامج مقدمي الخدمات وفق شروط الأهلية السارية، دون افتراض الحصول عليها.
