# مكتبة القدس — إرثي

علمٌ نافع، وأثرٌ باقٍ · [erthi.org](https://erthi.org)

تطبيق Android عربي لتصفح فهرس محلي وقراءة ملفات PDF الشخصية دون رفعها إلى خادم. النسخة التجريبية الحالية **1.6.0 (18)**، وليست إصدار إنتاج.

## المتاح

- بحث عربي في العنوان والمؤلف والتصنيف، مع تفاصيل ومفضلة محلية ووضع ليلي ونهاري.
- «كتبي وقراءة PDF»: استيراد ملف من منتقي Android والتحقق منه ونسخه إلى تخزين التطبيق الخاص.
- عرض صفحات PDF، السابقة والتالية والانتقال إلى رقم صفحة، وحفظ آخر صفحة واستكمالها لاحقًا.
- حذف النسخة المحلية بتأكيد، مع بقاء الملف الأصلي لدى مصدره.
- الحد 64 MiB للملف و512 MiB للمكتبة المحلية. لا أذونات تخزين واسعة ولا إذن دائم للملف الأصلي.

قاعدة الفهرس السابقة ومفضلتها ومخططها (الإصدار 2) محفوظة كما هي. تستخدم الملفات الشخصية قاعدة منفصلة ومجلدًا خاصًا. يحتوي الفهرس على سجل تجريبي معلن؛ لا تتضمن الحزمة كتبًا جاهزة أو نصوصًا دينية جديدة. راجع [تفاصيل القارئ وحدوده](docs/LOCAL_PDF_READER.md).

## حدود النسخة

صفحات PDF صور؛ لا استخراج نص أو بحث داخل الملف أو EPUB أو تكبير تفاعلي بعد. يقرأ قارئ الشاشة عناصر التحكم، لكنه لا يقرأ النص داخل صورة الصفحة. حذف التطبيق أو بياناته يحذف الكتب المحلية ومواضعها؛ احتفظ بالأصول. اختبار OPPO الفعلي والوصول وملفات متنوعة ما زال مطلوبًا.

لا حسابات أو مزامنة أو خادم في هذا الإصدار. اختيار الملف لا يمنح حقوق نشر أو توزيع؛ أضف ملفات يحق لك استخدامها.

## التشغيل والفحص

المتطلبات Java 17 وGradle 8.9 وAndroid SDK 35؛ minSdk 24 وtargetSdk 35. لا يتوفر Gradle Wrapper بعد.

```sh
python3 -m unittest discover -s tests -v
python3 tools/check_source_policy.py
gradle --no-daemon testDebugUnitTest assembleDebug assembleDebugAndroidTest lintDebug
# Disposable emulator only:
gradle --no-daemon connectedDebugAndroidTest
python3 tests/run_process_restart.py
```

اختبارات قاعدة الفهرس والترحيل تستخدم قواعد معزولة. تستخدم اختبارات PDF ملفات مولدة للاختبار ومزود ملفات داخل APK الاختبار فقط. اختبارات الواجهة وإعادة تشغيل العملية تحتاج محاكيًا مخصصًا، وتزيل ملفات اختبارها فقط. لا تشغّل مرحلتي prepare/verify يدويًا بترتيب عشوائي.
